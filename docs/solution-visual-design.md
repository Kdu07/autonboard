## 1. Introdução

Este documento apresenta o wireframe, o mockup e o guia visual do projeto. O objetivo é demonstrar a estrutura de navegação, a representação visual da interface e os padrões de harmonização da interface do usuário, garantindo uma experiência intuitiva, acessível e alinhada à identidade do parceiro.
